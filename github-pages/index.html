How to run Inkwell Studio

This GitHub Pages site is a static project overview—not the live app.

GitHub Pages only hosts static files. It cannot run the Next.js server, app APIs, database, or collaboration worker, so the editor and dashboards do not run on this page. To use the full app, run the project locally:

  1. Install prerequisites

    Install Node.js 18.17 or newer and Docker Desktop with Docker Compose.

  2. Clone the project and install packages

    git clone https://github.com/crnjihia/inkwell-studio.git
cd inkwell-studio
npm ci
Copy-Item .env.example .env

    The last command is for PowerShell. On macOS/Linux, use cp .env.example .env.

  3. Start the database and sample data

    npm run docker:up
npm run migrate --workspace=@inkwell/db
npm run seed --workspace=@inkwell/db

  4. Start the app

    npm run dev

    Open http://localhost:3000 for the web app. The local edge worker runs at http://localhost:8787.

Local defaults enable development authentication and mock AI/email, so external service keys are not needed to get started. For troubleshooting and tests, see the repository Quick Start .
